## FP Fix Summary (3 root causes, commit `517a4b7`)

### 1. Extractor call-visitor taint re-checking
**Root cause:** `tainted?(arg)` in the Crystal extractor's call visitor re-checked variable names against `TAINT_SOURCES`, overriding the assignment tracker's clean determination.  
**Fix:** For `Crystal::Var` args, use `@tainted_vars` tracking only.  
**Example:** `File.open(path)` where `path = mkstemp()` — extractor now correctly says `taint=False`.

### 2. Aggressive parameter seeding
**Root cause:** `seed_from_params` tainted ALL parameters named `path` in ALL functions, even private helpers called with safe data.  
**Fix:** Only seed params in functions where the extractor detected at least one tainted assignment.  
**Example:** `write_buffer_to_file(path, data)` — `path` no longer auto-tainted.

### 3. MissingTimeout without caller context
**Root cause:** `HTTP::Client.new` inside factory functions was flagged even though the caller sets timeouts.  
**Fix:** Check for `read_timeout=`/`connect_timeout=` setter calls anywhere in the same file.  
**Example:** `connect_to_ip()` returns a client → caller sets timeouts → no longer flagged.
