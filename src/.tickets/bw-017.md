# bw-017: concurrency.ml build_scopes — nodes from different files leak into wrong function

**Severity:** Medium  
**Status:** Fixed  
**File:** `lib/catseye_claws/concurrency.ml:179-202`

## Problem

`build_scopes` adds nodes to current function's body without checking `n.file = !current_file`. Nodes from file B get appended to a function defined in file A. Both `scope.ml` and `anatomy.ml` correctly group by file first.

## Fix

Group nodes by file before building scopes (use `Hashtbl` grouping like `scope.ml`), or simply reuse `Scope.build_scopes`.
