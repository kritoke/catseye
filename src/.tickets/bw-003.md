# bw-003: Resource leak in cache.ml file_hash on exception

**Severity:** High  
**Status:** Fixed  
**File:** `lib/catseye_engine/cache.ml:17-22`

## Problem

```ocaml
let ic = Stdlib.open_in path in
let content = Stdio.In_channel.input_all ic in   (* can raise *)
Stdlib.close_in ic;                               (* skipped on exception *)
```

If `input_all` raises (read error, I/O failure), the file descriptor leaks. Repeated failures exhaust FDs.

## Fix

```ocaml
Fun.protect ~finally:(fun () -> Stdlib.close_in ic) (fun () -> ...)
```
