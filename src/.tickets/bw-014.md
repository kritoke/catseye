# bw-014: propagate_cross_file propagates same-file taint

**Severity:** Medium  
**Status:** Fixed  
**File:** `lib/catseye_engine/propagate.ml:~95-120`

## Problem

Doc says "Check if source is tainted in any OTHER file" but code uses `Db.is_tainted_anywhere` which checks ALL files including the current one. Causes redundant propagation and potentially misleading cross-file taint records for same-file flows.

## Fix

```ocaml
let is_cross_file =
  Db.is_tainted_anywhere !taint_db_ref source_var
  && not (Db.is_tainted_in_file !taint_db_ref source_var node.file)
```

Note: requires adding `is_tainted_in_file` to `db.ml`.
