# bw-027: DRY — AI linter shared helpers across language rule files

**Severity:** Medium (DRY)  
**Status:** Fixed  
**Files:** All files in `lib/ai_linter/`

## Problem

- `expr_name`, `collect_app_names`, `walk_items_for_apps` duplicated across all 6 language rule files
- Hardcoded secrets prefix list (`"sk_"; "ghp_"; "AKIA"; "AIza"; ...`) duplicated 5×
- `is_test_or_spec_file` implemented 3× with different patterns
- Module aliases (`module List = Stdlib.List`) repeated everywhere

Crystal uses `include Crystal_rules_helpers` — other languages should do the same.

## Fix

Create `lib/ai_linter/linter_helpers.ml` with shared walking functions, secrets list, and test-file detection. Each language file does `include Linter_helpers`.
