# bw-002: DAG edges all point to sink, breaking flow trace chains

**Severity:** High  
**Status:** Fixed  
**File:** `lib/catseye_engine/dag.ml:113`

## Problem

In `trace_with_depth`, when a variable's assignment has an `ArgVar` source, the edge is created from the current propagator directly to `sink_id` (the global sink), not to the next propagator in the chain.

For chain `sink ← x ← y ← source`:
- Expected: `source → prop_y → prop_x → sink`
- Actual: `source → prop_y`, `prop_x → sink`, `prop_y → sink` (no edge `prop_y → prop_x`)

The DFS in `dag_to_flow_steps` terminates early because no edge points from `prop_y` to `prop_x`.

## Fix

Refactor `trace_with_depth` to return the current propagator's id. Thread the parent id through recursion. Only the top-level caller creates the edge to `sink_id`.
