# bw-012: Hardcoded path in gleam.ml grammar discovery

**Severity:** Medium  
**Status:** Fixed  
**File:** `lib/catseye_engine/gleam.ml:~310`

## Problem

```ocaml
let so_path = "/home/kritoke/.tree-sitter/gleam.so"
```

Developer-specific absolute path. Fails on every other machine.

## Fix

```ocaml
let home = try Stdlib.Sys.getenv "HOME" with Not_found -> "" in
let so_path = Stdlib.Filename.concat home ".tree-sitter/gleam.so" in
```
