# bw-020: Gleam TOML OSV results never cached

**Severity:** Medium  
**Status:** Fixed  
**File:** `lib/catseye_crowsnest/aggregator.ml:57-65`

## Problem

For `Shard_yml` dependencies, OSV results are cached. For `Gleam_toml`, the result is queried but never stored — the `match cache` block is a no-op (`| Some _c -> ()`).

## Fix

Call `Cache.store_osv` in the Gleam_toml branch, matching the Shard_yml pattern.
