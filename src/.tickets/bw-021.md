# bw-021: manifest.ml — out-of-bounds access in YAML parser

**Severity:** Medium  
**Status:** Fixed  
**File:** `lib/catseye_crowsnest/manifest.ml:76`

## Problem

```ocaml
else if Stdlib.String.length c_line > 0 &&
        (c_line.[dep_indent] = ' ' || c_line.[dep_indent] = '\t') then
```

If `dep_indent` exceeds `String.length c_line`, this raises `Invalid_argument("index out of bounds")`. The length check `> 0` is insufficient — needs `> dep_indent`.

## Fix

```ocaml
else if Stdlib.String.length c_line > dep_indent &&
        (c_line.[dep_indent] = ' ' || c_line.[dep_indent] = '\t') then
```
