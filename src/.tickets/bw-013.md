# bw-013: Worker pool loses buffered NDJSON data between calls

**Severity:** Medium  
**Status:** Fixed  
**File:** `lib/catseye_engine/worker_pool.ml:~100-130`

## Problem

`read_response` creates fresh local buffer each call. If a single `Unix.read` returns data spanning two NDJSON lines, the second line is consumed from the kernel buffer but lost when `read_response` returns because the local buffer is discarded.

## Fix

Add `mutable leftover : Buffer.t` to the `worker` record. Initialize in `spawn_worker`. Use `w.leftover` instead of creating a local buffer.
