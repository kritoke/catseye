# bw-019: Invalid JSON + JSON injection in rules and crowsnest

**Severity:** Medium  
**Status:** Fixed  
**Files:** `lib/catseye_rules/ai_format.ml:18`, `lib/catseye_crowsnest/osv.ml:88-89`

## Problems

1. **ai_format.ml:18** — Control chars (< 0x20) written raw to JSON. RFC 8259 §7 requires `\uXXXX` escaping. Produces invalid JSON.

   Fix: `Buffer.add_string b (Printf.sprintf "\\u%04x" (Char.to_int c))`

2. **osv.ml:88-89** — OSV query JSON built via `sprintf` with no escaping of package name/version. Names containing `"` break JSON.

   Fix: Use Yojson (already a dependency) to build the payload.
