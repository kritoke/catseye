# bw-006: Option.bind discards valid escript path in elixir_extractor.ml

**Severity:** High  
**Status:** Fixed  
**File:** `lib/catseye_cli/elixir_extractor.ml:257-262, 328-333`

## Problem

`Option.bind` chains escript path lookups: if first directory has the escript, bind calls continuation which tries second directory. If second fails, returns `None` — losing the valid first result.

## Fix

```ocaml
let escript_path_opt = List.find_map ~f:try_escript try_escript_paths
```
