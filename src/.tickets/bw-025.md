# bw-025: DRY — Extract shared XML parser from crystal_ts.ml and gleam.ml

**Severity:** Medium (DRY + fixes bw-011)
**Status:** Fixed  
**Files:** `lib/catseye_engine/crystal_ts.ml:168-340`, `lib/catseye_engine/gleam.ml:48-165`

## Problem

~300 lines of near-identical XML tokenizer/parser duplicated between the two files. Gleam's version correctly handles comments (`-->`) and self-closing tags; crystal_ts's versions are buggy (see bw-011).

## Fix

Extract `lib/catseye_engine/xml_parse.ml` with shared types (`xml`, `tok`), `tokenize`, `parse`, `find`, `children_where`, `attr`, `line_of`. Both extractors use the shared module. Fixes bw-011 automatically.
