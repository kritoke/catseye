# bw-007: export_rules.ml — off-by-one parsing bugs in KDL rule export

**Severity:** High  
**Status:** Fixed  
**File:** `lib/catseye_cli/export_rules.ml`

## Problem

Four off-by-one bugs in string slicing:

1. **Line 80**: `pos:8` should be `pos:9` for `"severity="` prefix. Severity stored as `"=High"`.
2. **Line 99**: `pos:8` should be `pos:9` for `"include \""` prefix. Language includes opening quote.
3. **Line 103**: Same for `"exclude \""`.
4. **Line 150**: `pos:0, len-1` should be `pos:1, len-2` for source names. Includes opening quote.
5. **Line 122**: `pos:5, len-5` should be `pos:5, len-6` for fix suggestions. Includes trailing quote.

## Fix

Correct each `pos`/`len` to skip the actual prefix/quote characters.
