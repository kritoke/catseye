# bw-023: gleam_rules.ml returns_result crashes on empty branches

**Severity:** Medium  
**Status:** Fixed  
**File:** `lib/ai_linter/gleam_rules.ml:1075-1081`

## Problem

```ocaml
| ECase (_, branches) ->
    ... || returns_result (snd (List.hd branches))
```

If `branches` is empty, `List.hd` raises `Failure`. Also, the code only recurses into the first branch's body, not all branches.

## Fix

```ocaml
| ECase (_, branches) ->
    List.exists (fun (pat, _) -> match pat with PType ("Result", _) -> true | _ -> false) branches
    || List.exists (fun (_, body) -> returns_result body) branches
```
