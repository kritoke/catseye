# bw-016: Bogus LOC for last class in file — class_graph.ml, hierarchy_smells.ml

**Severity:** Medium  
**Status:** Fixed  
**Files:** `lib/catseye_claws/class_graph.ml:107`, `lib/catseye_claws/hierarchy_smells.ml:84`

## Problem

When a class is the last one in its file, `end_line = 1000000`, so `loc = 1000000 - start_line`. Produces absurdly inflated LOC counts that trigger false positives in blob/large_class/hierarchy detectors. `scope.ml` correctly computes real last line from sorted node list.

## Fix

Apply same real-end computation from `scope.ml`:
```ocaml
let real_end =
  if end_line >= 1000000 then
    let max_line = List.fold_left (fun acc n -> max acc n.line) start_line sorted in
    max_line + 1
  else end_line
```
