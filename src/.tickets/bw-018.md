# bw-018: Inconsistent flag_prefixes between flat and AST smell engines

**Severity:** Medium  
**Status:** Fixed  
**Files:** `lib/catseye_claws/extra_smells.ml:285-289`, `lib/catseye_claws/extra_smells_ast.ml:292-294`

## Problem

AST engine includes `"is_"` and `"has_"` in flag prefixes while flat engine explicitly excludes them. Same codebase analyzed via two paths produces different FlagArgument findings.

## Fix

Extract `flag_prefixes` to shared module. Decide on single source of truth.
