# bw-005: .heex files routed to Elixir parser but rejected

**Severity:** High  
**Status:** Fixed  
**Files:** `lib/catseye_ast/parse.ml:23`, `lib/catseye_ast/elixir_mapper.ml:152`

## Problem

`parse.ml` routes `.heex` files to `Some Elixir`, but `elixir_mapper.ml` only accepts `.ex`/`.exs`. All `.heex` files fail with "Not an Elixir file".

## Fix

Add `.heex` to the extension check in `elixir_mapper.ml:152`:
```ocaml
if not (check_suffix ".ex" || check_suffix ".exs" || check_suffix ".heex") then ...
```
