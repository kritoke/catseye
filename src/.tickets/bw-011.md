# bw-011: Crystal XML tokenizer mishandles self-closing tags and comments

**Severity:** Medium  
**Status:** Fixed  
**File:** `lib/catseye_engine/crystal_ts.ml:242, 248-255`

## Problem

1. Self-closing tags with attributes (`<tag attr="val"/>`) not recognized because the check looks at tag name for trailing `/` instead of the raw attribute string. `gleam.ml` does this correctly.
2. Comment parsing stops at first `>` inside comment instead of `-->`. `gleam.ml` handles this correctly.

## Fix

Both fixed by extracting a shared XML parser (see bw-025). Alternatively, port gleam's correct logic to crystal_ts.
