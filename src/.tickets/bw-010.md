# bw-010: Severity classification fragile in aggregator.ml

**Severity:** High  
**Status:** Fixed  
**File:** `lib/catseye_crowsnest/aggregator.ml:29-32`

## Problem

- Prefix `"MOD"` is 3 chars but `sub s 0 4` extracts 4 chars — `"MODERATE"` doesn't match.
- Mixed case values (`"High"`, `"Critical"`) fail.
- Overlapping guards make logic non-obvious.

## Fix

Use case-insensitive matching with explicit list:
```ocaml
let is_critical_severity s =
  let s = String.lowercase_ascii s in
  String.length s >= 4 &&
  let prefix = String.sub s 0 4 in
  List.mem prefix ["crit"; "high"] || s = "critical" || s = "high"
```
