# bw-008: anti_singleton.ml — wrong end_line for all classes beyond the first

**Severity:** High  
**Status:** Fixed  
**File:** `lib/catseye_claws/anti_singleton.ml:136-139`

## Problem

All classes use `OldList.nth class_nodes 1` (the 2nd class's line) as `end_line` regardless of which class is being iterated. Causes false positives for early classes and false negatives for later ones.

## Fix

Iterate with index `i`, use `(i+1)`-th class as boundary:
```ocaml
let end_line =
  if i + 1 < OldList.length class_nodes then
    (OldList.nth class_nodes (i + 1)).Security_node.line
  else Stdlib.Int.max_int
```
