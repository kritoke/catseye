# bw-024: ETryCatchFinally and EUse return 0 without recursing in claws

**Severity:** Low  
**Status:** Fixed  
**Files:** `lib/catseye_claws/anatomy_ast.ml:147`, `lib/catseye_claws/complexity_ast.ml:90`

## Problem

`ETryCatchFinally` wraps try_body, optional rescue_clauses, and optional ensure_body. Returning 0 silently discards any nested complexity/nesting depth. A function with 15 nested ifs inside a try block shows nesting depth 0 for that branch. Same for `EUse` in anatomy_ast.

## Fix

Recurse into children for ETryCatchFinally and EUse.
