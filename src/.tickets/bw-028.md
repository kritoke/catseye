# bw-028: DRY — Crystal mapper JSON helpers + XML position helpers across mappers

**Severity:** Medium (DRY)  
**Status:** Open  
**Files:** `crystal_mapper.ml`, `crystal_hierarchical_mapper.ml`, 6+ tree-sitter XML mappers

## Problem

- JSON helpers (`string_of_json`, `int_of_json`, etc.) duplicated between crystal_mapper.ml and crystal_hierarchical_mapper.ml
- XML position/range helpers (`position_of_xml`, `range_of_xml`, `children_with_field`) duplicated across 6+ tree-sitter XML mappers
- `expr_full_name` duplicated between `to_security_node.ml` and `of_catseye_ast.ml`
- Language-to-string conversion duplicated in `to_security_node.ml` and `of_catseye_ast.ml`

## Fix

- Extract `json_helpers.ml` for Crystal mappers
- Extend `tree_sitter_xml.ml` with position/range helpers
- Move `expr_full_name` and `lang_to_string` to shared utility
