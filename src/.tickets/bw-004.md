# bw-004: Command injection via unquoted file paths in Crystal mappers

**Severity:** High  
**Status:** Fixed  
**Files:** `lib/catseye_ast/crystal_mapper.ml:226`, `lib/catseye_ast/crystal_hierarchical_mapper.ml:411`

## Problem

File paths wrapped in single quotes but not escaped. Paths containing `'` (e.g. `it's_test.cr`) break the shell command. `crystal_plugin.ml` correctly uses `Filename.quote`; the mappers don't.

```ocaml
let cmd = Stdlib.Printf.sprintf "%s '%s'" extractor_cmd path
```

## Fix

```ocaml
let cmd = Stdlib.Printf.sprintf "%s %s" 
  (Stdlib.Filename.quote extractor_cmd) 
  (Stdlib.Filename.quote path)
```
